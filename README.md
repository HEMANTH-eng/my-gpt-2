# MyGPT: Custom GPT-style Language Model from Scratch

A modular Python and PyTorch implementation of a GPT-style Large Language Model built completely from scratch.

## Project Structure
- `config/`: Configuration definitions and schema
- `models/`: PyTorch model components (Transformer, Attention, Embeddings, Head)
- `tokenizer/`: BPE and custom tokenizer modules
- `dataset/`: Dataset loading, tokenization, and streaming data loaders
- `training/`: Training loop, evaluation, optimizer, and checkpoint manager
- `utils/`: Logging, random seed control, metrics, and helper functions
- `tests/`: Unit and integration test suite
- `docs/`: Architecture diagrams, training guides, and setup instructions
